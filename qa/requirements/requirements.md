# Job Tracker - Requirements Specification

## 1. Purpose
The Job Tracker API allows to create, retrieve, update, and delete job records.

---
## 2. Functional Requirements

### FR-001 - Create a job
The system shall allow users to create a job by sending POST request to `/jobs` .

### FR-002 - Retrieve a job
The system shall allow users to retrieve a specific job record by sending GET request to `/jobs/{job_id}`.

### FR-003 - Retrieve all jobs
The system shall allow users to retrieve a list of job records.

### FR-004 - Update a job
The system shall allow users to update an existing job record.

### FR-005 - Delete a job
The system shall allow users to delete an existing job record.

### FR-006 - Persist job data
Successfully created or updated job records shall be persisted in the PostgreSQL database.

---

## 3. Job entity

A job record contains the following fields:

- `id` (UUID) - unique identifier. **Generated by DB**.
- `title` (str, required) - job title. 
- `stack` (str, required) - stack of required skills.
- `experience` (int, not required*) - number of years for applying to the vacancy. **0 by default**.
- `apply` (bool, not required*) - job application status. **False by default**.

*Confirm the optionality and defaults against the intended API contract.

## 4. API requirements

### API-001 - Endpoint Behavior:

|Method|Route         |Description              |Status-code    |
|------|--------------|-------------------------|---------------|
|GET   |/jobs         |Get list of all vacancies|200 OK         |
|GET   |/jobs/{job_id}|Get job by its ID        |200 OK         |
|POST  |/jobs         |Create a new job         |201 Created    |
|PATCH |/jobs/{job_id}|Update an existing job   |200 OK         |
|DELETE|/jobs/{job_id}|Delete an existing job   |204 No Content*|

*Confirm the status code against the intended API contract.

### API-002 - Job creation response

A successfully created job shall return next body:
```
{   
    "id": str UUID,
    "title": str,
    "stack": str,
    "experience": int,
    "apply": bool
}
```

### API-003 - Job not found
When a requested job ID does not exist, the API shall return HTTP 404 Not Found.

### API-004 - Invalid input
When a request contains data violates the validation requirements, the API shall return HTTP 422 Unprocessable Entity.

## 5. Validation requirements

### VR-001 - Title
The `title` string shall not be an empty string, whitespace-only string, or null.

### VR-002 - Stack
The `stack` string shall not be an empty string, whitespace-only string, or null.

### VR-003 - Experience
The `experience` shall not be an empty integer and shall be greater than or equal to 0.

### VR-004 - Apply
The `apply` field shall accept only not empty boolean value.
