# BUG-009 - `GET /jobs/{job_id}` returns 404 instead of 422 with invalid ID 
## Preconditions
- API is running.
- Database is running.

## Test Data
`job_id = "job_id_55"`

## Steps to Reproduce
1. Send a `GET` request to `/jobs/{job_id}` with test data.
2. Verify response status-code.
3. Verify the response body.

## Expected Result
1. Response status is `422 Unprocessable Entity`
2. Response body indicates that {job_id} has an invalid UUID format.


## Actual Result
1. Response status is 404 Not Found.
2. The API treats the invalid UUID as a non-existing job instead of rejecting the invalid ID format.
