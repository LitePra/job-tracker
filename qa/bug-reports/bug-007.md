# BUG-007 - job created with unknown fields  
## Preconditions
- API is running.
- Database is running.

## Test Data
```
{
    "title": "Java Backend Developer",
    "stack": "Java",
    "experience": 2,
    "salary": 590,
    "company": "Microsoft"
}
```
## Steps to Reproduce
1. Send a `POST` request to `/jobs` with the test data.
2. Verify the response status code and body.
3. Verify whether the job was created in the database. 

## Expected Result
- Response status is 422 Unprocessable Entity.
- Database remains unchanged (no new records created).

## Actual Result
- Response status is 201 Created.
- A new job is created in the database without unknown fields (`salary` and `company`).
