# BUG-011 - `GET /jobs` returns 500 instead of 200
## Preconditions
- API is running.
- Database is running.
- Defect records exist in the database.

## Steps to Reproduce
1. Send a `GET` request to `/jobs`.
2. Verify response status-code.
3. Verify response body.
4. Compare returned jobs with records in the database.

## Expected Result
1. Request is sent successfully.
2. Response status is `200 OK`
3. Response body contains list of jobs.
4. Returned jobs and their fields match the corresponding records in the database.


## Actual Result
1. Response status is 500 Internal Server Error.
2. No returned list of jobs.

## Additional information
The defect occurs due to the presence of defective records in the database. Pydantic validation fails once it tries to validate them.
